## Processing notes

* Every CJK unified ideograph in the configured Unicode version gets a record.
  BabelStone data is used when present; otherwise all CHISE sequences for the
  character are used (including CHISE's `@apparent` sequences).
* BabelStone's numbered unencoded components (`{1}`, `{2}`, …) are replaced by
  the approximate IDS fragments suggested in its file header, or by `？` where
  none is given. CHISE entity references for unencoded components (`&CDP-…;`,
  `&GT-…;`, `&AJ1-…;`, …) become `？`; references to glyph variants of IDS
  operators (`&U-i001+2FF1;`) become the operator itself.
* Components are everything in a sequence apart from operators and `？`, except
  that the second operand of the subtraction operator ㇯ is excluded, since it
  names what is *removed*. Components of all of a character's sequences
  (regional variants) are combined, then expanded recursively.
* Stroke counts are the first Unihan `kTotalStrokes` value. CJK Strokes count
  as 1; radical forms take the count of their equivalent unified ideograph.
